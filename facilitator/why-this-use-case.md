# Why We Chose C5 — Elevate Technician Support

**The choice:** From Schneider's seven Customer Support candidates (C1–C7), we
built the bootcamp around **C5 – Elevate Technician Support** ("technical answers
from manuals and installed base"). It is the strongest *teaching vehicle* because
it exercises the full Microsoft Foundry capability set in one safety-critical
scenario — while each alternative showcases only a subset.

## Contrast with the alternatives
- **C1 Customer Intent** — classification/routing only; no grounding or
  structured-data tools.
- **C2 Customer Knowledge Management** — essentially RAG alone; no function tools
  or safety stakes.
- **C3 Case Management** — a workflow/state build; process-heavy, thin on
  Foundry's grounding and trust primitives.
- **C4 Quality Evaluation** — *is* the evaluation capability, which C5 already
  teaches as Lab 06; too narrow to anchor a workshop.
- **C6 Proactive Tracking** — predictive/analytics and event pipelines; more
  data-engineering, less agentic.
- **C7 Proactive Contract Renewal** — CRM/propensity workflow; business-process
  heavy, low on grounding.

## Why C5 wins
- **Capability-complete:** persona, function tools over installed-base data,
  manual grounding (File Search + Azure AI Search), orchestration, observability,
  evaluation, and Content Understanding — one lab each, each fixing the previous
  one's weakness.
- **Safety makes trust tangible:** answers drive on-site actions on live
  electrical equipment, so citations, tracing, and evaluation are essential, not
  optional — the trustworthiness lessons land hard.
- **A superset path:** C5 contains the building blocks of the others — grounding
  (C2), orchestration (C3), quality scoring (C4). Master C5 and the team can
  build C1, C2, C3, C4, C6, and C7 themselves.
- **Right for the audience:** rich, structured, domain-real content that a
  beginner→intermediate group can build in a half-day (~2 h teaching + 2 h labs).

**Bottom line:** C5 delivers the broadest, most transferable Foundry skill set
with the clearest business and safety payoff — the best return on a half-day
investment.
